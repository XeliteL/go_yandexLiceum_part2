№1
Напишите функцию WriteString(s string, w io.Writer) error, которая записывает строку s в место назначения с помощью интерфейса w. 
Если возникает ошибка, функция должна возвращать её, иначе — nil.

№2
Напишите функцию ReadString(r io.Reader) (string, error), которая читает данные с помощью r и возвращает их в строковом виде. 
Если возникает ошибка, функция должна возвращать пустую строку и ошибку, иначе — строку и nil.

№3
Создайте структуру UpperWriter с полем UpperString string и реализуйте интерфейс io.Writer. 
Метод Write должен переводить строку в верхний регистр и записывать данные в поле UpperString. Если возникает ошибка, функция должна возвращать её.

№4
Напишите функцию Copy(r io.Reader, w io.Writer, n uint) error, которая копирует n байт из r в w. Если количество байт, 
доступных для чтения, меньше n, функция должна копировать все данные, а если возникает ошибка — возвращать её.

№5
Напишите функцию Contains(r io.Reader, seq []byte) (bool, error), которая должна найти в данных первое вхождение байт seq, которые доступны через Reader r. 
Если последовательность найдена, программа возвращает true, nil, иначе false, nil. Если возникает ошибка, функция должна возвращать false и ошибку.
